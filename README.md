# مدورا

مدورا یک وب‌اپ قابل نصب برای برنامهٔ دارو، ثبت مصرف و موجودی، قرارهای پزشکی، روتین‌ها و آب است. نسخهٔ عمومی در [medorapp.ir](https://medorapp.ir/medication/) اجرا می‌شود.

با نصب وب‌اپ، صفحه‌ها و داده‌های محلی پس از اولین بارگذاری آفلاین هم در دسترس‌اند. اعلان‌های پس‌زمینه از Web Push استفاده می‌کنند. ورود اختیاری است و سوابق روی دستگاه نگهداری می‌شوند. کاربر می‌تواند از وب بکاپ رمزدار بگیرد یا فایل رمزدار نسخهٔ قبلی اندروید را بازیابی کند.

## اجرای محلی

پیش‌نیاز Node.js نسخهٔ ۲۲ یا بالاتر است.

```bash
cd web
npm ci
npm run dev -- --port 8800
```

- [وب‌اپ](http://localhost:8800/medication/)
- [گالری طراحی](http://localhost:8800/design/)
- [پنل مدیریت](http://localhost:8800/admin/)

`npm run build` قالب‌ها، استایل و فهرست کش آفلاین را دوباره می‌سازد. پس از تغییر فایل‌های `web/ui/` این دستور را اجرا و صفحه را تازه کنید.

## ساختار

| مسیر | مسئولیت |
|---|---|
| `web/ui/layout/`، `screens/` و `forms/` | پوسته، صفحه‌ها و فرم‌های HTML |
| `web/ui/assets/icons/` | تعریف‌های SVG که هنگام ساخت در HTML قرار می‌گیرند |
| `web/ui/styles/` | استایل‌های صفحه، فرم، رنگ و رفتار دکمه‌ها |
| `web/public/medication/features/` | رفتار و نمایش هر قابلیت |
| `web/public/medication/domain/` | قواعد برنامه، زمان، دوز و موجودی |
| `web/public/medication/shared/` | ذخیره‌سازی، ترجمه و کنترل‌های مشترک |
| `web/public/medication/assets/` | تصویرها و مجموعهٔ SVG روتین |
| `web/src/` | Worker، حساب، اعلان و تبلیغات |
| `web/ui/gallery/` و `web/public/design/` | قالب و رفتار گالری طراحی با دادهٔ نمونه |

گالری، قالب‌ها و اجزای وب‌اپ را در حالت روشن و تیره، فارسی و انگلیسی و عرض‌های موبایل نمایش می‌دهد. «نمایش چرخه» و اکسنت اناری گزینه‌های آزمایشی گالری‌اند. برای تغییر رنگ، از `web/ui/styles/theme.css` و فهرست اکسنت‌ها در `web/public/medication/styles/theme.js` شروع کنید. برای تغییر یک SVG، فایل همان خانواده را در `web/ui/assets/icons/` یا `web/public/medication/assets/` ویرایش کنید.

## آزمون و انتشار

```bash
cd web
npm test
npm run test:care
npm run test:alarms
```

شاخهٔ `deploy` انتشار خودکار Cloudflare را اجرا می‌کند. [راهنمای تنظیم حساب، اعلان و انتشار](web/README.md)

کد نسخهٔ بومی اندروید در تاریخچهٔ Git و شاخه‌های انتشار قبلی موجود است. وب‌اپ مستقیماً با Node.js ساخته می‌شود.
