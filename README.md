# Medora

Medora یک اپلیکیشن بومی اندروید برای ثبت مصرف آب، مدیریت برنامهٔ دارو و یادآوری قرارهای پزشکی است. زبان پیش‌فرض فارسی است و انگلیسی نیز از تنظیمات قابل انتخاب است. برنامه با Kotlin و Jetpack Compose ساخته شده و اطلاعات را به‌صورت محلی روی دستگاه نگه می‌دارد.

## قابلیت‌ها

- **امروز:** خلاصه مصرف آب، ثبت سریع ۱۵۰، ۲۵۰ و ۵۰۰ میلی‌لیتر، نوبت‌های دارو و قرارهای پیش رو.
- **آب:** ثبت مقدار و زمان دلخواه، مشاهده روزهای گذشته، ویرایش و حذف ثبت‌ها، هدف روزانه و نمایش پیشرفت.
- **داروها:** ثبت نام و دستور مصرف، برنامه بر اساس روزهای هفته یا تاریخ‌های مشخص، ویرایش، توقف و حذف برنامه.
- **ساعت مصرف:** یک ساعت پیش‌فرض ۰۸:۰۰، انتخابگر ۲۴ساعته، افزودن ساعت با دکمهٔ +، ویرایش و حذف ساعت‌های اضافی؛ از ۱ تا ۱۲ ساعت بدون تکرار.
- **پیگیری نوبت‌ها:** وضعیت در انتظار، مصرف شد، مصرف نشد و تعویق ۱۰دقیقه‌ای؛ حفظ سوابق ثبت‌شده پس از تغییر یا حذف برنامه دارو.
- **قرارها:** نام پزشک، تاریخ، ساعت، منطقه زمانی محل، مکان و توضیحات؛ یادآوری از صبح روز قرار و تکرار یک‌ساعته یا دوساعته تا قبل از نوبت، به‌علاوه یادآوری زودتر اختیاری.
- **تنظیمات:** بخش‌های آب، قرارها و اعلان‌ها؛ انتخاب زبان فارسی/انگلیسی و تقویم شمسی/میلادی؛ انتخابگر ساعت، هدف و فاصلهٔ یادآوری آب، گزینه‌های بیشتر جمع‌شونده و پیش‌نمایش اعلان.

رابط با زبان انتخاب‌شده بین راست‌به‌چپ و چپ‌به‌راست تغییر می‌کند. تقویم شمسی برای نمایش و ورود تاریخ با Android ICU تبدیل می‌شود؛ تاریخ‌های داخلی و زمان نوبت‌ها همچنان مستقل از قالب نمایشی ذخیره می‌شوند. قالب تاریخ در صفحه‌ها، فرم‌ها، اعلان‌ها و انتخابگر تاریخ از تنظیم تقویم پیروی می‌کند. ارقام فارسی در رابط فارسی و ارقام لاتین در رابط انگلیسی استفاده می‌شوند. نام دارو و دستور مصرف را کاربر وارد می‌کند.

## پیش‌نیازهای توسعه

| مورد | تنظیم پروژه |
| --- | --- |
| سیستم‌عامل دستگاه | Android 8.0 به بالا، API 26+ |
| Compile / Target SDK | 35 |
| Android Gradle Plugin | 9.4.0 |
| Gradle Wrapper | 9.6.0 |
| افزونه Kotlin Compose | 2.4.21 |
| Compose BOM | 2025.03.00 |
| هدف بایت‌کد Java / Kotlin | JVM 17 |

یک Android Studio سازگار با ابزارهای بالا، JDK 17 یا جدیدترِ سازگار با Gradle و Android SDK لازم است. از Gradle Wrapper داخل ریپو استفاده کنید. نسخه‌های وابستگی در `build.gradle.kts` و `app/build.gradle.kts`، و نسخه Gradle در `gradle/wrapper/gradle-wrapper.properties` تعریف شده‌اند.

## اجرا در Android Studio

1. پوشهٔ `medora` را باز کنید؛ ریشه‌ای که `settings.gradle.kts` در آن قرار دارد.
2. SDK Platform 35 و Build Tools 36.0.0 را از SDK Manager نصب کنید.
3. Gradle JDK را تنظیم کنید و منتظر پایان Gradle Sync بمانید. دریافت اولیهٔ ابزارها و کتابخانه‌ها به اینترنت نیاز دارد.
4. گوشی با USB debugging یا شبیه‌ساز API 26 به بالا را انتخاب کنید و ماژول `app` را اجرا کنید.
5. داخل برنامه اعلان‌ها را فعال کنید. برای یادآوری دقیق، مجوز مربوط را هم از تنظیمات برنامه بدهید. یادآوری آب در ابتدا خاموش است و باید جداگانه فعال شود.

مسیر SDK هر توسعه‌دهنده در `local.properties` تنظیم می‌شود؛ این فایل در Git نگهداری نمی‌شود.

## ساخت و آزمون

در ریشهٔ پروژه، روی Windows:

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

روی Linux یا macOS:

```sh
./gradlew testDebugUnitTest assembleDebug
```

خروجی نصب آزمایشی در `app/build/outputs/apk/debug/app-debug.apk` است. گزارش آزمون‌ها در `app/build/reports/tests/testDebugUnitTest/index.html` ساخته می‌شود. برای انتشار، امضای Release را با کلید انتشار خود تنظیم کنید؛ کلیدهای امضا نباید وارد ریپو شوند.

آزمون‌های JVM شامل ۳۲ تست JUnit هستند: ۵۲ بررسی CoreChecks در یک تست، ۸ تست یادآوری قرار، ۴ تست زبان/تقویم و ۱۹ تست بازگشت باگ‌ها. آزمون‌های Android instrumentation تقویم و تغییر حریم خصوصی اعلان‌های موجود را بررسی می‌کنند؛ برای اجرای آن‌ها دستگاه یا شبیه‌ساز لازم است. گردش کار `.github/workflows/android.yml` آزمون‌های JVM، ساخت APK، کامپایل instrumentation و Lint را اجرا می‌کند.

یادآوری‌های عقب‌افتاده تا ۲۴ ساعت گذشته بازیابی می‌شوند. هر نوبت دارو مستقل نمایش داده می‌شود؛ تکرارهای عقب‌افتاده آب و هر قرار به آخرین پیام مربوط ادغام می‌شوند تا پس از تأخیر، اعلان‌های تکراری یک‌باره نمایش داده نشوند. آب فقط در روز جاری و داخل بازه فعال اعلان دارد؛ پایان بازه غیرشامل است (مثلاً بازهٔ ۰۸:۰۰ تا ۲۲:۰۰ شامل خود ۲۲:۰۰ نیست).

## ساختار ریپو

```text
app/
  build.gradle.kts                 تنظیمات ماژول اندروید
  src/main/
    AndroidManifest.xml           مجوزها و مؤلفه‌های برنامه
    java/ir/medora/health/
      MainActivity.kt             صفحه‌ها و رابط اصلی
      Editors.kt                  فرم‌های ثبت و ویرایش
      SettingsDialog.kt           تنظیمات دسته‌بندی‌شده
      HealthViewModel.kt          وضعیت رابط و اجرای تغییرات
      Domain.kt                   مدل‌ها و منطق برنامه‌ریزی
      Repository.kt               ذخیره‌سازی و Android Keystore
      Codec.kt                    تبدیل داده‌ها به/از JSON
      Encryption.kt               رمزگذاری AES-GCM
      Reminders.kt                اعلان‌ها، alarm و receiverها
    res/                          نام برنامه، تم، آیکون‌ها و فونت
  src/test/java/ir/medora/health/  آزمون‌های منطق برنامه
docs/                             معماری، اعتبارسنجی و آزمون روی دستگاه
branding/logo.svg                 منبع مشترک لوگو و آیکون‌ها
gradle/wrapper/                   Gradle Wrapper
```

نام پروژه `Medora`، namespace کد `ir.medora.health` و شناسهٔ نصب `ir.medora.health.android` است. نام نمایشی برنامه، عنوان تنظیمات و عنوان اعلان خصوصی در `app/src/main/res/values/strings.xml` تعریف شده‌اند.

## داده‌ها و یادآوری‌ها

اطلاعات در فضای خصوصی برنامه با AES-256-GCM رمزگذاری می‌شوند و کلید در Android Keystore قرار دارد. Repository تغییرات را به‌ترتیب اجرا می‌کند و فایل‌ها با AtomicFile نوشته می‌شوند. برنامه مجوز اینترنت ندارد و برای استفاده روزمره به حساب کاربری یا سرور نیاز ندارد.

آب و دارو از ساعت محلی گوشی پیروی می‌کنند؛ قرار به منطقه زمانی ثبت‌شده برای محل آن وابسته است. AlarmManager نزدیک‌ترین دسته یادآوری را زمان‌بندی می‌کند و پس از اجرا، دسته بعدی را می‌سازد. صف هنگام تغییر ساعت، تغییر منطقه زمانی، راه‌اندازی مجدد دستگاه و ارتقای برنامه بازسازی می‌شود.

اعلان دارو نام دارو، ساعت و دستور مصرف را نمایش می‌دهد و دکمه‌های «مصرف کردم» و «۱۰ دقیقه بعد» دارد. اعلان قرار شامل نام پزشک، تاریخ و ساعت، مکان و توضیحات ثبت‌شده است. متن کامل با بازکردن اعلان دیده می‌شود. نمایش جزئیات پیش‌فرض روشن است و می‌توان آن را در بخش اعلان‌های تنظیمات خاموش کرد. نمایش روی صفحهٔ قفل همچنان تابع تنظیمات حریم خصوصی اندروید است. اعلان آب امکان ثبت ۲۵۰ میلی‌لیتر یا تعویق ۱۰دقیقه‌ای را فراهم می‌کند.

پیش‌فرض قرارها، شروع ساعت ۰۸:۰۰ روز نوبت و تکرار هر ۲ ساعت است. ساعت شروع و فاصلهٔ ۱ یا ۲ ساعت در تنظیمات قابل تغییرند. یادآوری دقیقاً در زمان نوبت یا پس از آن ارسال نمی‌شود. برای نوبت‌های زودتر از ساعت شروع، یک ساعت قبل خبر داده می‌شود. در فرم هر قرار می‌توان یادآوری یک ساعت قبل، دو ساعت قبل یا روز قبل را هم انتخاب کرد؛ زمان‌های هم‌پوشان فقط یک اعلان تولید می‌کنند.

قالب داده نسخهٔ ۵ است و داده‌های نسخه‌های ۲ تا ۴ بدون حذف سوابق خوانده می‌شوند. ترجیح زبان و تقویم به تنظیمات رمزگذاری‌شده افزوده شده‌اند؛ داده‌های قدیمی به فارسی/شمسی پیش‌فرض می‌شوند و زمان‌های ثبت‌شده تغییر نمی‌کنند.

## تعویض لوگو و آیکون

فقط `branding/logo.svg` را جایگزین کنید و برنامه را دوباره بسازید. Gradle از همین فایل لوگوی داخل برنامه، آیکون تطبیقی لانچر و نشان اعلان را تولید می‌کند. SVG باید مربع و متشکل از مسیرهای سادهٔ `<path>` با رنگ هگزادسیمال باشد؛ متن، stroke و transform را هنگام خروجی‌گرفتن به مسیر تبدیل کنید. راهنمای کامل در [branding/README.md](branding/README.md) است.

## محدودیت‌ها و تغییر نام

- پشتیبان‌گیری و انتقال داده در نسخه فعلی پیاده نشده و پشتیبان‌گیری خودکار سیستم غیرفعال است. حذف برنامه یا پاک‌کردن فضای ذخیره‌سازی، داده‌های آن را حذف می‌کند.
- با تغییر شناسهٔ نصب به `ir.medora.health.android`، Medora از نظر اندروید یک برنامهٔ جدا از نسخهٔ قبلی است. داده‌ها، مجوزها و یادآوری‌های نصب قبلی خودکار منتقل نمی‌شوند؛ مجوزهای نصب جدید را جداگانه فعال کنید.
- محدودیت باتری، Doze و نبود مجوز یادآوری دقیق ممکن است اجرای اعلان را به تأخیر بیندازند. پس از Force stop، برنامه را دوباره باز کنید تا صف بازسازی شود.
- تقویم شمسی و میلادی برای نمایش و ورود تاریخ پشتیبانی می‌شوند؛ تاریخ‌های داخلی به‌صورت ISO/Gregorian نگهداری می‌شوند. حساب کاربری و همگام‌سازی ابری وجود ندارد.

## طراحی Soft Wellness

رابط جدید بر اساس [تصویر مرجع تأییدشده](docs/design/approved-reference.png) ساخته شده است: کارت آب با پیشرفت حلقه‌ای، لیوان آب، کارت‌های دارو و قرار، فرم‌های پایین صفحه، صفحه خوش‌آمد و حالت تیره. تقویم فعالیت و گزارش‌های مصرف از منوی سه‌نقطهٔ بالای صفحه در دسترس‌اند. داده‌ها، رمزگذاری و یادآوری‌ها حفظ شده‌اند.

[راهنمای پیاده‌سازی و بررسی تصویری](docs/design/IMPLEMENTATION.md) شامل مسیر اجزا و آزمون‌های رابط است. گردش کار `Wellness UI screenshots` اسکرین‌شات‌های واقعی Compose را برای مقایسه با تصویر مرجع تولید می‌کند.
