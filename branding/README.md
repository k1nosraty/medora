# لوگو و آیکون Medora

فقط `branding/logo.svg` را جایگزین کنید و دوباره برنامه را بسازید. وظیفهٔ Gradle به نام `generateBrandResources` از همین فایل، لوگوی داخل برنامه، پیش‌زمینه آیکون لانچر و نشان تک‌رنگ اعلان را می‌سازد. خروجی‌ها در `app/build/generated/branding/res` قرار می‌گیرند و نباید دستی ویرایش شوند.

SVG باید مربع با `viewBox="0 0 N N"` باشد. شکل‌ها را به `<path>` تبدیل کنید؛ رنگ‌ها با `fill` هگزادسیمال شش‌رقمی، `fill-opacity` و `fill-rule` پشتیبانی می‌شوند. متن، گروه، transform، stroke، CSS، gradient و تصویر را پیش از خروجی‌گرفتن به مسیرهای ساده تبدیل کنید. لوگو را داخل مربع و با حاشیه مناسب قرار دهید.

هم رنگ و هم شکل لوگو از SVG خوانده می‌شوند. رنگ پس‌زمینه لانچر در `app/src/main/res/values/colors.xml` تعریف شده است. آیکون‌های تطبیقی و تک‌رنگ اندروید از همان شکل استفاده می‌کنند.

لوگوی اولیه همان نشان Spa از Google Material Design Icons است که پیش‌تر داخل برنامه استفاده می‌شد؛ تحت مجوز Apache 2.0. فایل مجوز در `branding/LICENSE` قرار دارد.
