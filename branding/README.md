# نشان مدورا

`logo.svg` منبع نشان دفتر دستگاه است و ساخت Vite آن را در `/journal/art/logo.svg` قرار می‌دهد. آیکون‌های محصول اصلی در [دارایی‌های وب](../apps/web/product-assets/public/) قرار دارند. آدرس‌های عمومی آن‌ها برای نصب‌های قبلی ثابت‌اند.

`LICENSE` منبع مجوز آیکون است. ساخت وب همین فایل را در `/ICON-LICENSE.txt` منتشر می‌کند. نشان اولیه از آیکون Spa مجموعهٔ Google Material Design Icons با مجوز Apache 2.0 آمده است.

منابع Gradle و وظیفهٔ قدیمی `generateBrandResources` به نسخهٔ بومی اندروید در تاریخچهٔ Git تعلق دارند. قواعد طراحی فعلی در [راهنمای طراحی](../docs/DESIGN_SYSTEM.md) آمده‌اند.
