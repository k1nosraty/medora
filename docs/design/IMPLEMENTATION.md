# Emerald Sanctuary implementation

The active redesign specification is [EMERALD-SPEC.md](EMERALD-SPEC.md). Approved mockup identifiers: 01-12 and 19-36. Views 13-18 are rejected and must not be used as layout references.

The redesign ships as one integrated change. Persisted medication appearance identifiers, hydration records, reminder scheduling and appointment behavior remain compatible. UI-only theme selection is stored separately in `medora_ui`.

Native vectors provide the shared three-leaf mark and botanical artwork. Standard Android notification templates retain control of layout; medication colors are represented by the large icon only when reminder details are public.

Build, device checks and screenshot review are required before the single review package is ready.
