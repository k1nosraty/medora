# نتیجه بررسی نسخه Android 0.2.0

تاریخ بررسی: ۲۰۲۶-۱۰-۰۸.

## اجراشده و موفق

- **۵۲ بررسی منطق مستقل** در CoreChecks با Kotlin 2.1.0 و JVM 17 اجرا شد؛ نتیجه `52 checks passed`.
- مجموع، باقی‌مانده و پیشرفت آب؛ ویرایش، حذف و تفکیک روزهای گذشته.
- ورودی ارقام فارسی/عربی، ساعت‌های تکراری و تاریخ‌های مشخص.
- برنامه روزانه چند نوبت، روزهای هفته، تاریخ‌های مشخص؛ چهار وضعیت، تعویق ده‌دقیقه‌ای، ویرایش ساعت، توقف و حذف برنامه با حفظ مصرف ثبت‌شده.
- بازه آب، یک تکرار، ثبت آب و حذف تکرار، تعویق، توقف موقت، خاموش‌بودن و رسیدن به هدف.
- دو یادآوری قرار، ویرایش زمان، لغو و حذف؛ ثابت‌ماندن زمان قرار با سفر گوشی.
- روز تغییر ساعت تابستانی واقعی Europe/Berlin: ساعت مصرف ۰۸:۰۰ ثابت و فاصله روزها ۲۳ ساعت؛ تعویق دارو از نیمه‌شب عبور می‌کند.
- شناسه اعلان پایدار، JSON داده و صف، نسخه schema، رمزگذاری AES-GCM، IV تازه، نوشتن فایل رمزگذاری‌شده و خواندن پس از بستن فایل؛ تشخیص دستکاری و کلید اشتباه.
- قبل از رضایت، هیچ یادآوری زمان‌بندی نمی‌شود؛ لغو رضایت تحویل صف موجود را مسدود می‌کند.
- **تمام فایل‌های Kotlin برنامه**، شامل UI Compose، ViewModel، Keystore، AtomicFile و receiverها، با Kotlin 2.1.0 و افزونه واقعی Compose Compiler با موفقیت کامپایل شدند. classpath شامل کتابخانه‌های رسمی AndroidX با نسخه‌های مطابق BOM و API Android 15 از بسته Robolectric بود. فقط کلاس تولیدی R در این بررسی با شناسه‌های موقت جایگزین شد؛ آن فایل در پروژه تحویلی نیست.
- Manifest و سه XML منابع با parser XML معتبر بررسی شدند. پشتیبانی RTL، جهت اجباری RTL Compose، locale فارسی و فونت همراه در کد بررسی شد.

## اجرا نشده

**APK در این محیط ساخته نشده است.** اجرای Gradle Wrapper هنگام دانلود distribution با خطای Java `Network is unreachable` متوقف شد. Android SDK کامل/شبیه‌ساز اینجا نصب نیست. بررسی Kotlin جایگزین build کامل Gradle، پردازش منابع، lint یا اجرای برنامه روی گوشی نیست.

JUnit Gradle روی محیط حاضر اجرا نشده؛ همان سناریوهای CoreChecks مستقیماً روی JVM اجرا شدند. ذخیره‌سازی Keystore و AtomicFile روی دستگاه، ظاهر و پیمایش رابط، اعلان‌های واقعی Android، اقدام اعلان در process بسته، reboot، مجوزها و رفتار Doze نیازمند فهرست آزمون `DEVICE-QA.md` هستند.

## بازتولید

با Android Studio، JDK 17 و SDK 35 پس از Gradle Sync:

```sh
./gradlew testDebugUnitTest assembleDebug
```
در Windows از `gradlew.bat` استفاده کنید. DomainTest اجرای ۵۲ بررسی را به JUnit متصل می‌کند. workflow اختیاری GitHub همان دستور را اجرا و APK debug را به‌عنوان artifact ذخیره می‌کند؛ این workflow در این محیط اجرا یا به حسابی منتشر نشده است.
