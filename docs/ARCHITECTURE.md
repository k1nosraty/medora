# معماری و مسیر توسعه

رابط Compose ← HealthViewModel ← Repository ← فایل‌های رمزگذاری‌شده خصوصی.
منطق زمان‌بندی در Planner مستقل از Android است. Reminders آن را به AlarmManager و NotificationManager تبدیل می‌کند. UI و receiverها از executor متوالی Repository استفاده می‌کنند؛ هر تغییر ابتدا داده تازه را می‌خواند و پس از نوشتن موفق، وضعیت رابط را به‌روز می‌کند. خطای خواندن یا کلید، داده موجود را با داده خالی جایگزین نمی‌کند.

شناسه نوبت دارو از شناسه برنامه + تاریخ محلی + ساعت ساخته می‌شود. اطلاعات نام و توضیح در Dose کپی می‌شوند تا ویرایش یا حذف برنامه، تاریخچه ثبت‌شده را تحریف نکند. گذشته با وضعیت در انتظار باقی می‌ماند تا کاربر آن را مشخص کند؛ بدون اعلام کاربر به «مصرف نشد» تبدیل نمی‌شود. تغییر برنامه، نوبت‌های آینده در انتظار را بازسازی می‌کند. نوبت به‌تعویق‌افتاده فقط وقتی برنامه اصلی هنوز فعال و ساعت/روز معتبر باشد اعلان می‌گیرد.

AlarmManager یک PendingIntent ثابت برای نزدیک‌ترین دسته دارد. صف رمزگذاری‌شده قبل از تنظیم alarm ذخیره می‌شود. با دریافت alarm، داده تازه خوانده و اعتبار هر یادآوری دوباره بررسی می‌شود. صف بعدی پیش از نمایش اعلان ثبت می‌شود. بازسازی صف، alarm قبلی را لغو می‌کند. رضایت کاربر و مجوز سیستم پیش از ثبت alarm بررسی می‌شوند. دریافت‌کننده‌ها exported نیستند و PendingIntentها immutable هستند. شناسه اعلان‌ها در داده حفظ می‌شود؛ اقدام تکراری اعلان با token ثبت‌شده دوباره اعمال نمی‌شود.

## پشتیبان‌گیری آینده

Schema JSON نسخه ۲ دارد. خروجی آینده باید با انتخاب صریح کاربر از Storage Access Framework ایجاد شود و رمز مستقل قابل بازیابی داشته باشد؛ کلید Keystore دستگاه قابل انتقال نیست. فایل‌های فعلی `.enc` را به‌تنهایی نباید به‌عنوان backup قابل بازیابی معرفی کرد. واردکردن باید پیش از جایگزینی، نسخه schema، حدود مقادیر، منطقه زمانی، شناسه‌های یکتا و رمز را بررسی کند؛ سپس در یک نوشتن اتمیک جایگزین و صف alarm بازسازی شود. پیش از فعال‌کردن backup سیستمی باید سیاست حفظ اطلاعات سلامت و رمزگذاری قابل انتقال مشخص شود.

## محدودیت نسخه اولیه

Android 8+، تاریخ میلادی، داده محلی بدون حساب و همگام‌سازی، هدف آب فعلی برای مقایسه روزهای گذشته، توقف آب یک‌ساعته، تعویق دارو ده‌دقیقه‌ای، بازه آب در همان روز. انتقال داده خودکار از نسخه Flutter پیاده نشده است؛ شناسه نصب این پروژه جداست. پاک‌کردن Storage یا حذف برنامه داده را حذف می‌کند.
