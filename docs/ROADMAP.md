# Outstanding gates

| Gate | Evidence required before release |
| --- | --- |
| A · Code | Full implementation of each required feature and normal runtime entry point, production review and a frozen candidate |
| B · Features | End-to-end parity for all rows in FEATURE_PARITY.md, including delivery of reminders with the app closed, generation 2 account lifecycle, service operations and administration |
| C · Data | Independent hosted namespace census, frozen authorized source, physical and application-level mappings, all pending operations, client generation fencing and reconciliation against that complete source |
| D · Security | Complete legacy identity/session continuity, all family permissions, private field protection and hosted configuration checks |
| E · Performance | Verify the larger offline install, representative large histories, physical devices and field responsiveness |
| F · UI | Bilingual mobile and desktop inspection for every rebuilt workflow and assistive-technology checks |
| G · Deployment | Hosted isolated Cloudflare integration, reverse coverage for outstanding mutation types, fleet fencing and a complete portable recovery drill |

The scope of the verified slice is in DEPLOYMENT.md. A production promotion must be evaluated against all seven gates.
