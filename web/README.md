# محصول مرجع و مسیر سازگاری مدورا

این پوشه هم منبع ظاهر محصول اصلی است و هم پیاده‌سازی نسخهٔ سازگاری. ساخت بازسازی‌شده از `ui/`، دارایی‌ها و ماژول‌های فعال مرورگر در `public/` استفاده می‌کند و بخش‌های React را در زمان ساخت جایگزین می‌کند. ورودی `src/worker.mjs` پیاده‌سازی حساب، خانواده، یادآوری، عملیات و فایل‌های قدیمی Durable Objects را برای سازگاری و بازیابی نگه می‌دارد.

## ساخت و آزمون

از ریشهٔ مخزن:

```sh
npm ci --prefix web
npm --prefix web run build
pnpm test:compat
npm --prefix web run test:browser
```

ساخت، قالب‌ها، استایل، بسته‌های مرورگر، دارایی Workbox و مجوز آیکون را در `web/public` تولید می‌کند. برای دیدن محصول کامل با API از [راهنمای اجرای محلی](../README.md) استفاده کنید. اجرای سازگاری از مسیرهای `/medication/`، `/design/`، `/admin/` و `/pilot/` استفاده می‌کند. `wrangler.jsonc` تنظیم Worker نسخهٔ سازگاری است. تنظیم جداگانهٔ Workerd محلی و حالت مستقل PostgreSQL در [راهنمای Cloudflare](../docs/CLOUDFLARE_DEPLOYMENT.md) قرار دارند.

## مسیرهای بازیابی

| مسیر | مسئولیت |
| --- | --- |
| `public/medication/shared/storage.js` | حفظ و ارتقای IndexedDB اصلی، با نسخه‌ها و رکوردهای قدیمی |
| `public/medication/features/backups/` | باز کردن بکاپ رمزدار وب و اندروید و نگه‌داشتن مسیرهای ماژول قدیمی |
| `scripts/migrate-care.mjs` | بررسی و بازیابی آرشیو رمزدار بخش‌بندی‌شدهٔ `MEDSRV02` |
| `scripts/migrate-care-v1.mjs` | خواندن و بازیابی آرشیوهای `MEDSRV01` |
| `test/fixtures/android-medora-v1.medora` | نمونهٔ سازگاری برای آزمون خواندن بکاپ اندروید |
| `src/operations/` | مجوز مهاجرت، تشخیص فرمت‌ها، بررسی اثرانگشت و ادامهٔ بازیابی چندبخشی |

آرشیو منطقی Worker تنها داده‌هایی را در بر می‌گیرد که ابزار نسخهٔ مربوطه فهرست می‌کند. وضعیت نشست، زمان‌بندی و کلیدهای تداوم باید متناسب با فرمت آرشیو بررسی شوند. ابزار نسخهٔ قدیم برای مهاجرت مستقیم به PostgreSQL طراحی نشده است. برای تطبیق کامل namespace، حساب‌ها، فایل‌ها و نوشتن‌های پس از انتقال از [راهنمای مهاجرت](../docs/MIGRATION.md) استفاده کنید. اطلاعات کاربران، کلیدها، فایل‌های Wrangler محلی و آرشیوهای عملیاتی در Git نگهداری نمی‌شوند.

## حفظ رفتار نسخهٔ قدیم

- قابل‌دسترسی بودن IndexedDB و مجوز اعلان به مبدأ وب وابسته است. هنگام انتقال، آدرس عمومی برنامه را ثابت نگه دارید.
- برنامه پس از ثبت سوابق آفلاین دوباره همگام می‌شود. تغییر هم‌زمان روی چند دستگاه با بازبینی نسخه و انتخاب کاربر حل می‌شود. پوشاندن خطای همگام‌سازی با پاک‌کردن دادهٔ سایت ممکن است تغییرات ثبت‌نشده را از بین ببرد.
- نسخه‌های کلید حساب، نشست، رمز و یادآوری را برای بازکردن داده‌های بازیابی‌شده حفظ کنید. کوکی حساب با کلید بازیابی متن خصوصی یکی نیست. روی دستگاه جدا، اعتبار ورود، بازیابی رمز، نشست و لغو دسترسی را بررسی کنید. [امنیت و مرز داده‌ها](../docs/SECURITY.md)
- برای آزمون واقعی یادآوری روی iPhone، وب‌اپ را در Safari نصب کنید، روی دادهٔ آزمایشی اعلان را فعال کنید و دریافت پس از بستن برنامه و قفل گوشی را بررسی کنید. نتیجهٔ پذیرش پیام در سرویس Push به‌تنهایی نمایش اعلان روی گوشی را ثابت نمی‌کند.
