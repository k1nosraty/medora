# نسخهٔ وب مدورا

صفحهٔ اصلی وب، برنامهٔ چندمرحله‌ای دارو، دوز و موجودی را روی دستگاه نگه می‌دارد. با فعال‌کردن اعلان، منطقهٔ زمانی، الگوی تکرار و موعدهای ردشده به همراه اشتراک Push به سرور فرستاده می‌شوند. نام دارو، دوز، موجودی و سوابق مصرف در مرورگر می‌مانند. متن اعلان عمومی است و لمس آن برنامهٔ همان روز را باز می‌کند.

## ساخت و انتشار

به Node.js نسخهٔ ۲۲ به بالا و JDK نیاز دارید. از ریشهٔ ریپو اجرا کنید.

```bash
bash gradlew -p care-core jvmTest buildWebEngine
cd web
npm ci
npm test
npm run test:care
npm run pilot:secrets -- https://github.com/k1nosraty/medora
npm run dev
```

دستور ساخت کلید فقط برای نصب تازه است. فایل‌های محلی `.dev.vars` و `.pilot-secrets.json` محرمانه‌اند. فقط مقدار `PILOT_ACCESS_CODE` را به افرادی بدهید که قرار است اعلان را فعال کنند. کلیدهای VAPID و امضای اشتراک را در انتشارهای بعدی حفظ کنید. اگر فایل‌های یک نصب قدیمی را دارید، برای `REMINDER_SIGNING_KEY` یک مقدار مستقل ۳۲ بایتی تصادفی به‌شکل هگز در هر دو فایل قرار دهید.

برای انتشار دائمی از حساب Workers Free استفاده کنید.

```bash
npx wrangler login
npm run deploy -- --secrets-file .pilot-secrets.json
```

دو Durable Object با SQLite روی Workers Free اجرا می‌شوند. هر نصب فقط یک alarm برای نزدیک‌ترین نوبت دارد. درخواست همگام‌سازی قدیمی، جای زمان‌بندی جدید را نمی‌گیرد. نوبت‌های هم‌زمان در یک اعلان جمع می‌شوند. تغییرات آفلاین تا اتصال و همگام‌سازی دوباره روی زمان‌بندی سرور اثر نمی‌گذارند. اگر نشانی سایت عوض شود، نصب و اجازهٔ اعلان باید روی نشانی جدید انجام شوند. دادهٔ مرورگر هم به نشانی قبلی وابسته است.

## آزمون آیفون

۱. نشانی HTTPS را در Safari باز کنید، به صفحهٔ اصلی اضافه کنید و از آیکون مدورا وارد شوید. در «اعلان نوبت دارو» کد فعال‌سازی را وارد کنید، دکمهٔ فعال‌سازی را بزنید و اجازهٔ اعلان بدهید.

۲. یک داروی آزمایشی برای چند دقیقهٔ آینده ثبت کنید. بعد از نمایش زمان «یادآوری بعدی»، برنامه را ببندید و صفحه را قفل کنید. با لمس اعلان، نوبت‌های همان روز باز می‌شوند.

۳. برای آزمون لغو، نوبت دیگری ثبت کنید و پیش از موعد آن را مصرف‌شده یا مصرف‌نشده علامت بزنید. بعد از همگام‌سازی، زمان یادآوری بعدی را بررسی کنید.

۴. صفحهٔ `/pilot/` ابزار ارسال فوری و یک دقیقه بعد را برای بررسی خود مسیر Push نگه می‌دارد. پذیرفته‌شدن پیام در سرویس Push با نمایش آن روی گوشی فرق دارد.
